# 経費クエスト（デモ）

経費精算をドラクエ風のゲームに変えた社内ツールのデモ版。

**公開URL**: https://bujirosai.github.io/keihi-quest-demo/

## これは何か

個人カードの立替を会社に精算するとき、「カードの明細」「会計サービス上の申請」「領収書」の三つを突き合わせて、
どの支出がどこに落ちるかを1行ずつ決めていく作業がある。地味で、量が多く、後回しにされる。

このツールはその作業を、月ごとの「モンスター退治」として組み直したもの。

- **しんじつのたて** — 5つの確認（未申請の取りこぼし・カード履歴との一致・二重申請・法人カードとの二重・証憑不足）を常時表示する
- **しょうごうしつ（月別）** — カード行と申請行を1:1で突き合わせ、残った行を「私費／経費:個人／経費:共通」などに1行ずつ判定する。判定が0件になるとその月は「かんぺき」
- **クエストログ** — 判定から自動で生えるタスク。会計サービス側で直したらチェックする
- **ファイルボックス** — 未添付の領収書を画像で見ながら、その場で個人／共通を判定する
- **掟** — 法人カードとの二重が疑われる行は、照合の根拠をメモに残さないと台帳が判定を受け付けない

## デモ版について

- 店名・金額・日付・領収書画像は**すべて架空の自動生成**。実在の取引・会社・人物とは関係がない
- 会計サービス（freee）にも実データにも接続していない。サーバもなく、HTML 1枚で動く
- 判定は閲覧者のブラウザ（localStorage）にのみ保存される。他の人には見えない。「さいしょから やりなおす」で消える
- 盤面は固定シードで生成しているので、誰が開いても同じ状態から始まる

## 中身

`index.html` 1ファイルのみ（自己完結・外部読み込みなし）。本番アプリの HTML から、
データに触る部分だけをデモ層に差し替えて機械的に生成している。
